# 👤 Vaultrix User Service

Manages the core identity and profile data for the Vaultrix platform.

## 🔑 Core Features
- User Registration & Authentication.
- Profile Management.
- RBAC (Role-Based Access Control).

## 🗄️ Persistence
Connects to the centralized **MongoDB** cluster using root authentication and secure environment variables injected via Helm.


## 🛡️ Security & Quality
This repository is part of the Vaultrix Secure Software Development Lifecycle (SDLC):
- **SonarQube**: Static analysis & Quality Gate.
- **Snyk**: Open-source vulnerability scanning.
- **Trivy**: Container image security scanning.
